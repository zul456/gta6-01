Velmara — a sun-soaked coastal open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty. Explore the city on foot and by car, steal cars, run six story jobs for the fixer Mara Voss, dodge the Velmara PD's wanted stars, and find the ten stash crates — all offline, in a desktop browser, from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD moves and drives, Shift runs, E enters and exits cars, F punches, click shoots, R reloads, Space is the handbrake, P pauses, M mutes.
